# The Green Adventure

## 1. Game Idea
The Green Adventure is a text-based adventure game set in Finland.
The player explores different places and helps protect the environment.

## 2. Objective
The objective is to solve environmental problems and earn points
by making environmentally friendly choices.

## 3. How to Play
1. Run main.py.
2. Enter your name and age.
3. The player must be at least 12 years old.
4. Choose a route from the main menu.
5. Select an action to help the environment.
6. View your score using option 4.
7. Choose option 5 to exit the game.

## 4. Game Routes
- Forest Route: Help protect the forest from rubbish.
- Lake Route: Help reduce plastic pollution.
- Town Route: Help people recycle and save electricity.

## 5. Classes
- Player: Stores the player's name, age, and score.
- Room: Stores the location, environmental problem, and solution.

## 6. Functions
- show_score(): Displays the player's score.
- show_room(): Displays information about a location.
- show_menu(): Displays the main menu.
- add_points(): Adds points to the player's score.
- solve_problem(): Returns a possible solution to a room's problem.

## 7. Sustainability
The game promotes environmental sustainability.
It encourages players to reduce waste, protect wildlife,
recycle materials, and save electricity.

## 8. How to Run
Open main.py in Python or Visual Studio Code and run the file.
